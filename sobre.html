Sobre o IFMarket

O que é o IFMarket?

O IFMarket é um projeto educacional de uma plataforma de anúncios voltada à comunidade do IFPR Campus Telêmaco Borba. Sua proposta é permitir que os usuários divulguem produtos, consultem anúncios e encontrem oportunidades de compra.

Aprendendo na prática

O sistema está sendo desenvolvido com os estudantes do curso de Tecnologia em Análise e Desenvolvimento de Sistemas (TADS), na disciplina de Tecnologias Web.

Durante as aulas, o projeto permite aplicar os conhecimentos de HTML e CSS na construção das páginas, dos formulários, da navegação e da apresentação dos anúncios.

O que estamos construindo?

  • Cadastro e acesso de usuários.
  • Publicação de anúncios de produtos.
  • Consulta aos anúncios disponíveis.
  • Visualização dos detalhes de cada produto.
  • Organização dos anúncios de cada usuário.

Projeto em desenvolvimento

O IFMarket evolui conforme os conteúdos trabalhados em aula. Os produtos, preços e imagens apresentados nesta versão são exemplos utilizados para fins didáticos.
